# YouTube Script Framework

Is skill ka use karke agent retention-optimized scripts likhta hai.

## Structure
1. **Hook (0-15s)** — bold claim ya question
2. **Bridge (15-30s)** — promise + credibility
3. **Body** — 3 value points, har point pe open loop
4. **CTA** — natural, value-linked

Read `details/retention.md` for advanced retention tactics.
